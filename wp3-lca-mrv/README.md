# WP3: Lifecycle and financial assessment

**Owner:** Group 3

## Purpose

Quantify the environmental performance of the regenerative system, feed the verified result back into the financial model, and define the measurement protocol for every claimed outcome.

## What goes in this folder

LCA scope and dataset, results, measurement protocol, field-test plan, social LCA.
