# WP2: Product regeneration

**Owner:** Group 2

## Purpose

Define what it means for a product to be regenerative in engineering terms, and formalise it in the system model: requirements, architecture, and the ecological and social flows that the conventional model does not represent.

## What goes in this folder

The regenerative SysML v2 model. It extends [SustainableTogether-Baseline v1.0.0](https://github.com/The-Sustainability-Virtual-Lab/SustainableTogether-Baseline/releases/tag/v1.0.0) and never overwrites it.
